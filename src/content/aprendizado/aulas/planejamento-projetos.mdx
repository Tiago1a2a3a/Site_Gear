## Objetivos

Definir escopo, separar responsabilidades e estabelecer evidências de conclusão. O exemplo será uma simulação de monitoramento, sem compra de peças ou promessa de funcionamento em campo.

## Escolha a menor demonstração útil

Em vez de começar por “construir uma estação completa”, proponha uma primeira entrega: ler uma lista de valores fictícios, identificar os inválidos e apresentar os demais com unidade.

Essa entrega exercita entrada, validação e saída. Ela pode ser concluída antes de escolher sensor, gabinete ou conexão de rede. Cada etapa seguinte deve responder a uma necessidade concreta.

## Separe contratos

| Parte        | Entrada           | Saída               | Evidência             |
| ------------ | ----------------- | ------------------- | --------------------- |
| Leitura      | Lista de exemplos | Um registro por vez | Ordem preservada      |
| Validação    | Registro          | Aceito ou rejeitado | Casos de limite       |
| Apresentação | Dados aceitos     | Tabela com unidade  | Leitura compreensível |

O contrato deve informar o comportamento em caso de erro. Não deixe essa decisão para a última etapa de integração.

## Organize o trabalho

1. Escreva o objetivo e o que ficará fora desta entrega.
2. Defina três critérios que possam ser demonstrados.
3. Prepare exemplos normais e inválidos.
4. Implemente uma parte de cada vez.
5. Integre e registre o resultado.
6. Atualize o próximo passo usando o que aprendeu.

## Diferencie plano de resultado

“Vamos medir temperatura” é uma proposta. “O sistema registrou cinco leituras simuladas” é um resultado observável. Uma página de projeto deve deixar essa diferença evidente, especialmente quando outras pessoas a usarão como referência.

## Exercício

Escreva uma proposta de uma página para um dos [projetos didáticos](/projetos). Inclua objetivo, contratos, critérios de conclusão, limitações e primeira demonstração. Evite definir datas ou responsáveis sem combiná-los com as pessoas envolvidas.
